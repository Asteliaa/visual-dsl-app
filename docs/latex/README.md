# Отчет по ПЗ1 в формате LaTeX

Файл `report.tex` содержит тот же отчет, что и `../Отчет_ПЗ1.docx` (титульный лист, цель, ход работы, 12 рисунков, 8 листингов, таблица, ответы на вопросы 25-27, выводы).

## Параметры оформления

Заданы в преамбуле `report.tex` по рабочему профилю СТП БГУИР 01-2024: A4, поля 30/15/20/20 мм, Times New Roman 14 pt, межстрочный интервал 18 pt, абзацный отступ 1,25 см, выравнивание по ширине, таблицы 12 pt с выравниванием по центру, пустая строка (18 pt) между элементами, вся латиница курсивом.

Официального LaTeX-шаблона по СТП 2024 на странице кафедры нет (открытые шаблоны есть только для СТП 2013 и 2017), поэтому формат собран по тем же числовым параметрам, что и версия для Word. Требования к рисункам, нумерации страниц и заголовкам стоит сверить с полным текстом СТП.

## Сборка

Нужны дистрибутив TeX (MiKTeX или TeX Live) и установленные в системе шрифты Times New Roman и Courier New (в Windows есть по умолчанию).

```bash
cd docs/latex
xelatex report.tex
xelatex report.tex
```

Запускать нужно именно `xelatex` (не `pdflatex`), два раза. Рисунки берутся из `../screenshots/`.

Файл сгенерирован скриптом из тех же данных, что и `.docx`; при правках текста меняйте оба варианта.
